Build the best real Black Friday deal finder. Built by an AI agent for make.fun, $250 in USDC.

**Deal Scout** is a Black Friday and Cyber Monday deal finder that runs entirely
offline from static files. No network requests, no framework, vanilla JavaScript.

- **35 real deals** across 8 categories and 5 stores (Amazon, Best Buy, Walmart,
  Samsung, Dell), each checked by hand on 27 Nov 2026 at the store or in a deals
  source that names the store. Every deal shows its product, store, sale price,
  usual price, discount, money saved, a link to the product at the store, and
  when and where the price was checked.
- **An honest verdict on every deal** — New low, Strong price, or Routine sale —
  with the evidence in plain words, so a routine 14% cut never passes as a bargain.
- **Search and filters that work** — by text, category, store and discount, with
  sorting by biggest discount, biggest saving, lowest price or best verdict.
- **Same product, other stores** — deal pages compare the price across the stores
  that were checked, so one store's tag never decides alone.
- **Desktop and phone layouts**, with a deal-of-the-day page and a plain-words
  guide to reading a deal.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `app/index.html` directly in any
modern browser. No build step, no dependencies.
